# Счётчик 0–9 (версия 2.0) на ATmega328P

## 📌 Описание
Улучшенная версия учебного проекта «Счётчик».  
Микроконтроллер **ATmega328P** управляет семисегментным индикатором (общий катод) и двумя кнопками:
- **Кнопка 1 (PB0)** - увеличение счёта.
- **Кнопка 2 (PB1)** - уменьшение счёта.

В отличие от первой версии, здесь добавлен **антидребезг** и **фиксация нажатия**, поэтому счётчик реагирует ровно на одно нажатие, а не пролетает несколько значений сразу.  
Проект собран и проверен в симуляторе **Proteus**.

## 🧰 Компоненты
- Микроконтроллер **ATmega328P**
- Семисегментный индикатор (общий катод)
- 7 резисторов **300 Ом** (токоограничивающие)
- 2 тактовые кнопки
- Провода, макетная плата (или Proteus)

## ⚙️ Принцип работы
- В `setup()` настраиваются порты:
  - `DDRD = 0xFF` - все пины порта D на выход (сегменты индикатора).
  - `DDRB = 0x00` - порт B на вход (кнопки).
  - `PORTB = 0x03` - включаем внутренние подтяжки на PB0 и PB1.
- В `loop()`:
  - На порт D выводится текущая цифра из массива `numbers[]`.
  - Проверяется нажатие кнопок с антидребезгом (`delay(20)` и повторная проверка).
  - При нажатии на PB0 счётчик увеличивается (после 9 идёт 0).
  - При нажатии на PB1 счётчик уменьшается (после 0 идёт 9).
  - После обработки нажатия программа ждёт отпускания кнопки, чтобы одно нажатие давало ровно один шаг.
